# Task Card 3: Ticker Mapping

任务：对节点 `[Z]` 枚举上市标的。

硬性规则：

1. 每个节点必须枚举至少一个 EU 标的：Xetra / 米兰 / 阿姆斯特丹 / 巴黎。确实没有就写 `EU: none exists`，禁止默认只扫美股。
2. 任何字段写 `需验证` / `需拆` / `unknown` / `[unverified]` 的候选，评级只准写 `PENDING`。
3. 对每个非 `PENDING` 候选，单独写一段“市场为什么还没定价它”的假说。
4. 假说必须引用证据：覆盖行数、6 个月相对板块超额收益、电话会词频。用“可能/或许”支撑的假说自动降级。
5. 引用会被随机抽查；发现一次编造，本批次全部降级重跑。

输出：

- US 候选表。
- EU 候选表。
- 坐标市场候选表。
- 非 PENDING 候选的逐票 mispricing hypothesis。
