# 数据源目录 v0.1

按两个维度排序：**证据质量**（Tier 1–3）和**机读友好度**（有无免费 API / 结构化数据）。
第一版优先做"Tier 1 + 有 API"的交集——质量和自动化成本同时最优。

## 第一优先级：Tier 1 且免费机读（v1 就该接入）

### 美国

| 来源 | 覆盖的发现入口 | 接入方式 | 备注 |
|---|---|---|---|
| **SEC EDGAR 8-K** | 重大合同、并购、高管变动、指引变化 | 免费 API：`efts.sec.gov/LATEST/search-index?q=...`；全文搜索 `efts.sec.gov/LATEST/search-index`；RSS/Atom feed 按 form type 订阅 | 8-K 的 Item 编号本身就是事件分类（Item 1.01 重大协议、2.02 业绩、5.02 高管变动、8.01 其他）——天然的 event_type 映射 |

## 判断"高质量"的四条标准

1. **法律责任**：披露方对内容承担法律责任（监管申报 > 新闻稿 > 采访 > 社媒）。
2. **双方确认**：交易对手是否也披露了同一事件。单方面披露一律降级。
3. **含金额与时间表**：有合同金额、交付时间的披露远优于"战略合作"。
4. **机读与可回溯**：有稳定 URL、发布时间戳、不可篡改（EDGAR 满分；微信文章接近零分）。

## v1 接入建议（按 ROI 排序）

1. **EDGAR 8-K（Item 1.01 / 2.02 / 8.01）+ Form 4（P 买入）**——免费 API、事件已预分类、法律责任最强。
2. **USAspending.gov**——政府合同入口，结构化程度最高的"经济影响可量化"来源。
3. **财报电话会点名提取**——企业关系入口最高产，但需要 NLP 提取，放第二阶段。
4. A 股 cninfo 公告流——如果要覆盖 A 股，这是唯一起点。
