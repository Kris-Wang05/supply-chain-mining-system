# Agent SOP

本文档把原始 SOP 转成 Codex 可执行的研究流程。目标不是给出买卖建议，而是生成可审计的候选表和证据链。

默认运行方式是单阶段任务卡，而不是一次性跑完整条流水线。上一阶段输出必须经用户审核并写入 repo，才允许作为下一阶段输入。Codex 是研究工人，用户是质检员。

## 输入

输入可以是：

- 一条主线名称，例如 `AI先进封装`、`AI电力`、`立法造舰`。
- 一个锚点事实，例如某项法案拨款、链主产能承诺、已签合同或已确认产品路线图。

## 执行范围

Codex 的能力边界是 Stage 0-5，但单次任务默认只执行一个 Stage：

1. Stage 0：主线登记与周期定位。
2. Stage 1：锚点事实采集。
3. Stage 2：工序分解与必然接单推导。
4. Stage 3：标的映射与可交易性过滤。
5. Stage 4：覆盖空白与定价检验。
6. Stage 5：红旗筛查。

Stage 6-8 只输出待人工回答的问题，不替代人的判断。任何请求如果要求直接从主线跳到候选评级，必须先拆成任务卡。

## Task Card First

优先使用 `docs/operating_playbook.md` 中的五张任务卡：

- 卡1：锚点采集。
- 卡2：工序分解。
- 卡3：标的枚举。
- 卡4：红旗尽调。
- 卡5：词频监控。

除非用户明确要求全链路草稿，否则不要一次性跑 Stage 0-5。即使跑全链路，所有含待验证字段的候选也只能标 `pending`。

## Stage 1 锚点纪律

合格锚点必须是能驱动订单传导的前瞻硬承诺：

- 产能承诺：wpm、月产能、年产能、cleanroom 面积、设备 install base。
- 数量承诺：片/年、艘/年、台/年、合同数量、法定采购数量。
- 金额承诺：capex budget、强制拨款、已签合同、backlog。
- 产品路线图：已确认的封装形态、die 数、HBM stack 数、电压/材料标准。

不合格锚点：

- 已发生收入占比、收入结构、毛利率、市场份额等结果性指标。它们只能作为背景，不得作为 Stage 2 推理燃料。
- 管理层目标、分析师预测、pipeline、MOU、LOI。
- 找不到原文或无法打开来源的数字。

每条锚点必须包含：

- 原文来源 URL。
- 日期。
- 来源等级。
- 原文短摘录。
- 数字、单位和时间范围。
- 是否为前瞻硬承诺。

无法打开来源或无法从原文摘录的锚点必须降级为 `[unverified]`，不得进入 Stage 2。

## Stage 2 推理纪律

从锚点到节点必须写清机械传导：

- `designed-in`：设计定点或法定配套。
- `sole-source`：单一来源。
- `per-unit-consumable`：按片、按台、按项目消耗。
- `capacity-gap`：链主产能不足导致外溢或扩产订单。
- `competitive-bid`：需要竞标，必然性降级。

若锚点缺失数量级，Stage 2 只能输出待验证假说，不得输出评级。

## Stage 3 标的枚举纪律

对每个工序节点，必须同时扫描：

- US：NYSE / NASDAQ / OTC。
- EU：Xetra / Milan / Amsterdam / Paris / London。
- 坐标市场：TW / JP / KR / HK，仅用于温度计，除非用户明确可交易。

每个节点至少列出一个 US 候选和一个 EU 候选；若不存在，必须写 `none found` 和搜索理由。不得默认美股池。

## Stage 4 定价检验纪律

每个候选必须单独完成三项检验：

- 覆盖密度：卖方数量、构成、是否已有美资大行深度覆盖。
- 重估检查：过去 6 个月相对板块指数的超额收益。
- 热词浓度：最近两次电话会或新闻稿里主线关键词频次变化。

每个 `A` 或 `B` 候选必须单独给出 mispricing hypothesis。全局假说不合格。

## Pending 评级规则

评级必须滞后于数据。只要候选字段里出现以下状态，禁止给 `A`、`B`、`C`：

- `unknown`
- `[unverified]`
- `需验证`
- `需拆`
- `TBD`
- `pending source`

这类候选只能给 `pending`、`坐标` 或 `出局`。补完锚点、纯度、定价检验和红旗后，才能升级为字母评级。

## 候选输出规则

每个候选必须包含：

- ticker 和交易所。
- 对应工序节点。
- 订单传导类型。
- 必然接单强度，1-5 分。
- 纯度比例或无法确认说明。
- 三项定价检验结果。
- 触发的 kill rules。
- 价格史备注。
- 综合评级：`A`、`B`、`C`、`pending`、`坐标`、`出局`。

`A` 或 `B` 候选必须额外写一段 mispricing hypothesis：解释市场为什么还没定价它，并列出证据。

## 评级约束

- `A`：证据链完整、传导强、红旗少、定价检验全阴性或可解释。
- `B`：证据链较完整，但仍有覆盖、纯度、流动性或价格史瑕疵。
- `C`：可以跟踪，但不满足 A/B 质量；不得包含待验证核心字段。
- `pending`：逻辑可能成立，但关键数字、来源、纯度、价格史或覆盖检验未完成。
- `坐标`：不可交易或纯度过低，但可作为产业温度计。
- `出局`：触发 kill rule，或关键事实无法验证。
